FinIQ – AI Financial Assistant
An intelligent AI-powered financial assistant built using Python and Gradio for smart financial analysis, interactive conversations, and AI-driven insights.
Overview
FinIQ is a modern AI-based financial assistant designed to help users interact with financial information in a simple and efficient way. The application provides an interactive Gradio interface where users can analyze financial data, ask finance-related questions, and receive AI-generated insights.

•	AI-powered financial assistant
•	Interactive Gradio web interface
•	Real-time financial insights
•	User-friendly UI

•	Data analysis support

Installation
1.	Clone the repository from GitHub
2.	Navigate to the project folder
3.	Install dependencies using pip install -r requirements.txt
4.	Run the application using python app.py
   
Usage
6.	Launch the application
7.	Open the Gradio interface in your browser
8.	Enter financial queries or upload financial data
9.	Receive AI-generated insights and analysis
